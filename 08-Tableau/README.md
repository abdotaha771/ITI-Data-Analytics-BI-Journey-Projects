# Module 08: Tableau

This module introduces Tableau for interactive data visualization, dashboard development, and communicating business insights.

---

## Learning Objectives

- Explore business data through interactive visualizations.
- Compare sales and profit across regions, states, segments, and sub-categories.
- Identify trends and patterns in monthly sales performance.
- Build a Tableau workbook that supports business analysis.

---

## Core Topics

- Tableau worksheets and visual analysis.
- Sales and profit analysis.
- Geographic and category-based comparisons.
- Dashboard insights and interpretation.
