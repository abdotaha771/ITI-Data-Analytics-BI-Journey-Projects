# Module 05: ETL Using SSIS

This module introduces the fundamentals of Extract, Transform, Load (ETL) workflows using SQL Server Integration Services (SSIS). It focuses on moving data between sources and destinations, applying transformations, and validating the results of an ETL package.

---

## Learning Objectives

- Understand the role of ETL in data warehousing and business intelligence.
- Build SSIS control-flow and data-flow workflows.
- Import, transform, merge, and export data.
- Use conditional transformations to separate records by business rules.
- Validate package outputs and maintain database backups.

---

## Core Topics

- SSIS packages and project organization.
- Control Flow and Data Flow tasks.
- Source and destination connections.
- Merge and Union All transformations.
- Conditional data splitting and flat-file outputs.
- SQL Server backup and restore considerations.
- Testing and validating ETL results.

By the end of this module, learners should be able to design a basic SSIS package, apply common data-flow transformations, export organized results, and verify that an ETL workflow produces the expected outputs.
