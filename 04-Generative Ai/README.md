# Module 04: Generative AI

This module introduces the foundations of generative AI in a practical, hands-on way. It focuses on understanding how AI tools can support data work, improve data cleaning workflows, and help analysts generate structured outputs from raw information.

---

## Learning Objectives

- Understanding the role of generative AI in modern data analytics workflows.
- Learning how to craft effective prompts for business and data tasks.
- Using AI tools to clean and transform unstructured or messy datasets.
- Comparing outputs from multiple AI models and evaluating quality.
- Recognizing the strengths, limitations, and responsible use of AI-generated content.

---

## Core Topics

- Prompt design and prompt engineering basics.
- AI-assisted data cleaning and preprocessing.
- Structured output generation from raw data.
- Comparing results across multiple AI models.
- Practical data tasks using generative AI workflows.
- Workflow automation with n8n and AI services.

## Practical Exercises

This day includes two practical generative AI tasks:

- AI_TASK_1: Data cleaning and normalization using a raw, messy CSV file, comparing outputs from multiple AI tools.
- AI_TASK_2: AI-assisted used car price prediction workflow, including prompt-based project refinement, dataset cleaning, and model benchmarking.

The first activity focuses on cleaning data with AI guidance, while the second extends the workflow into exploratory data analysis and model evaluation.

Day 25 introduces n8n and explores how workflow automation can connect applications, APIs, data sources, and generative AI services.

### Exercise Focus

- Clean the provided dataset.
- Improve data consistency and formatting.
- Use AI-generated outputs as a working reference.
- Compare the quality of results across multiple models.

---

## Module Outcome

By the end of this module, learners should be able to recognize how generative AI can accelerate data preparation and support analytical tasks while still requiring human review, validation, and critical judgment.
