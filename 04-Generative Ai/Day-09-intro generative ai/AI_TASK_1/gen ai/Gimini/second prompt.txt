Here is a detailed, step-by-step walkthrough for cleaning this dataset using Microsoft Excel.

---

### Step 1: Inspect & Set Up the Worksheet

1. Open your raw CSV file in Excel.
2. Select all data ($Ctrl + A$) and convert the range into a formal Excel Table by pressing **$Ctrl + T$** (ensure *"My table has headers"* is checked). This enables easy filtering, structured references, and banded rows.
3. Turn on the **Filter** dropdowns on each header if not already active ($Ctrl + Shift + L$).
4. Check the unique values and formats by clicking the filter arrow on each column to spot inconsistencies, blanks, and unusual numbers.

---

### Step 2: Remove Duplicate Records

1. Select any cell inside your table.
2. Navigate to the **Data** tab on the Ribbon $\rightarrow$ **Data Tools** group $\rightarrow$ click **Remove Duplicates**.
3. In the pop-up window, ensure all columns (**Duration**, **Date**, **Pulse**, **Maxpulse**, **Calories**) are selected.
4. Click **OK**. Excel will detect and remove the duplicate row for `2020/12/12` (original row 13), leaving unique daily records.

---

### Step 3: Clean and Standardize the `Date` Column

The raw date column contains single quotes (e.g., `'2020/12/01'`), an unformatted string (`20201226`), and a missing entry.

**A. Strip Single Quotes & Delimiters**

1. Select the `Date` column (Column B).
2. Press **$Ctrl + H$** to open the **Find and Replace** dialog.
3. In **Find what**, type `'` (single quote); leave **Replace with** completely blank.
4. Click **Replace All**.

**B. Fix Unformatted Number Dates**

1. Click the filter arrow on the `Date` header to locate irregular text formats like `20201226`.
2. Replace `20201226` with `2020/12/26` (or use the formula `=DATE(LEFT(B2,4), MID(B2,5,2), RIGHT(B2,2))` if dealing with bulk unformatted strings).

**C. Handle Missing Date (Blank Cell)**

1. Filter the `Date` column for **(Blanks)** to find the empty record between `2020-12-21` and `2020-12-23`.
2. Because the dataset represents a sequential daily log, manually enter `2020/12/22`.

**D. Apply Uniform Date Formatting**

1. Select the entire `Date` column.
2. Press **$Ctrl + 1$** to open **Format Cells**.
3. Go to the **Number** tab $\rightarrow$ select **Date** $\rightarrow$ choose the `YYYY-MM-DD` standard format (e.g., `2020-12-01`) and click **OK**.

### Step 4: Detect and Correct Numerical Outliers (`Duration`)

1. Insert a helper column named **Validation** with the formula:
```excel
=IF([@Pulse] > [@Maxpulse], "Error", "OK")
```

### Step 6: Impute Missing Values (`Calories`)

The `Calories` column contains blank cells on `2020-12-18` and `2020-12-28`.

1. Calculate the median or mean of the non-empty calorie entries in an empty cell outside the table:
```excel
=MEDIAN(Table1[Calories])
```

2. Filter the **Calories** column to display only **(Blanks)**.
3. Select the visible blank cells, type `291.2`, and press **$Ctrl + Enter$** to fill all selected blanks simultaneously.
