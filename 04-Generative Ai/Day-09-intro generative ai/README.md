# Day 09: Introduction to Generative AI

This day introduces practical generative AI workflows for data analysis and data preparation. The exercises focus on comparing AI-generated outputs, refining prompts, and using AI tools to accelerate cleaning, transformation, and model-building tasks.

---

## Tasks Included

### 1. AI_TASK_1

A hands-on data cleaning exercise using an unclean dataset and multiple AI tools. Learners compare how models handle the same raw data and prompt.

Key contents:

- the prompt.txt
- Un_Clean_Data.csv
- gen ai/
  - my note.txt
  - chat gpt/cleaned_data.csv
  - claude/Cleaned_Data.csv
  - deepseek/deepseek_csv_20260901_c4b602.csv
  - Gimini/Cleaned_Data.csv

### 2. AI_TASK_2

A more advanced AI-assisted project centered on used-car price prediction. This task includes data cleaning, feature engineering, model comparison, and final evaluation using a cleaned Excel dataset.

Key contents:

- best model.txt
- Cleaned_UsedCarsSA_Dataset.xlsx
- new model.py
- UNCLEANED_UsedCarsSA_Unclean_Ar.xlsx
- prompt documents for understanding and improving the project workflow

---

## Learning Focus

- Prompt design and iteration
- AI-assisted data cleaning
- Structured output generation
- Comparing model outputs and evaluation quality
- Using AI as a practical support tool while validating results manually

---

## Outcome

By the end of the day, learners should be able to use generative AI for both simple data tasks and more analytical data science workflows, while still applying critical thinking to review and validate the results.
