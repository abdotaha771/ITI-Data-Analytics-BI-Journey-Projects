# Module 02: Advanced SQL Query

This module builds on the foundations of relational database design and SQL by applying advanced querying techniques, T-SQL programming, database objects, data modification, SQL Server security, and analytical SQL features.

---

## Learning Objectives by Day

- **Day 05 — Advanced SQL Queries:**
  - Writing aggregate queries using `COUNT`, `AVG`, `MIN`, and `MAX`.
  - Applying `DISTINCT`, `ISNULL`, `COALESCE`, joins, subqueries, and date filtering.
  - Using `GROUP BY`, `HAVING`, and `LIKE` for analytical data retrieval.
  - Using ranking functions such as `ROW_NUMBER`, `RANK`, and `DENSE_RANK` with the `OVER` clause.
  - Creating tables from query results with `SELECT INTO`.
  - Writing T-SQL scripts using variables, control-of-flow statements, and reusable database objects.
  - Understanding SQL Server security concepts, including logins, users, roles, and permissions.
  - Creating views for reusable query results.
  - Querying and modifying data in the ITI and AdventureWorks databases.
- **Day 06 — Stored Procedures and Triggers:**
  - Creating stored procedures with parameters and control-of-flow logic.
  - Creating triggers to control data modifications and prevent specific inserts.
  - Auditing inserts, deletes, and budget updates with user and date information.
  - Working with the ITI and Company databases.
