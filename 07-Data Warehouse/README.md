# Module 07: Data Warehouse

This module introduces the foundations of data warehousing and compares common architectures and loading strategies for analytical data.

---

## Learning Objectives

- Understand the Inmon and Kimball data warehouse architectures.
- Distinguish between full-load and incremental-load strategies.
- Recognize how architecture and loading choices support analytical workloads.

---

## Core Topics

- Inmon versus Kimball approaches.
- Full load versus incremental load.
