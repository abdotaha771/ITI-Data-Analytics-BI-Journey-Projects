# Day 15: Introduction to Data Warehousing

This day introduces core data warehousing concepts and compares the architectures and loading strategies used in analytical data platforms.

---

## Lab Files

- [Lab.txt](Lab.txt): Written exercises covering data warehouse architectures and loading strategies.

---

## Topics Covered

- Inmon versus Kimball approaches.
- Full load versus incremental load.

---

## Outcome

By the end of the day, learners should be able to compare the Inmon and Kimball approaches and distinguish between full and incremental loading for analytical requirements.
