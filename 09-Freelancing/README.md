# Module 09: Freelancing

This module introduces the fundamentals of freelancing and provides practical guidance for starting a freelance career through the Mahara Tech freelancing track.

---

## Learning Objectives

- Understand the fundamentals of freelancing and independent work.
- Identify a suitable freelance direction based on skills and interests.
- Learn how to prepare for freelance work and present services professionally.
- Explore the onboarding process for common freelance platforms.
- Build awareness of the practical steps needed to start offering services online.

---

## Core Topics

- Freelancing basics and career preparation.
- Finding a suitable freelance path.
- Getting started on Khamsat, Mostaql, and Upwork.
- Building a freelance profile and presenting services.
- Understanding the first steps toward finding freelance opportunities.

## Module Outcome

By the end of this module, learners should understand the freelance work model, choose a suitable direction, and have a practical starting point for creating profiles and offering services on freelance platforms.
