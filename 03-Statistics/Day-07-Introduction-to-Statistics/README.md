# Day 07 — Introduction to Statistics

This day introduces the statistical concepts used in analytics, including how to summarize data, measure variability, and interpret distributions using a real dataset.

---

## Files in This Folder

- `Lab 07.pdf` — practical lab handout for the day
- `README.md` — topic guide and learning objectives

---

## Topics Covered

- What statistics is and why it matters in analytics
- Population vs. sample
- Measures of central tendency: mean, median, and mode
- Measures of spread: range, variance, and standard deviation
- Comparing population and sample statistics
- Descriptive analysis using a real dataset
- Data visualization for distribution and comparison

---

## Lab Focus

This lab uses the Titanic dataset from Seaborn to calculate and interpret descriptive statistics for the `fare` column and visualize distributions across passenger class and age.

### Included in the exercise

- Loading the dataset
- Calculating mean, median, mode, and range
- Computing variance and standard deviation for both population and sample formulas
- Visualizing:
  - passengers per class
  - age distribution
  - fare distribution by passenger class

## Objectives

- Summarize numeric data using descriptive statistics
- Understand variability and distribution patterns
- Distinguish between sample and population calculations
- Practice reading and interpreting statistical output
