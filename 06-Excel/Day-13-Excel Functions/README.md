# Day 13: Excel Functions

This day introduces practical Excel functions for organizing data, performing calculations, and supporting everyday analytical tasks.

---

## Lab Files

- [Lab.xlsx](Lab.xlsx): Practice workbook with the required Excel exercises.
- [Lab_solution.xlsx](Lab_solution.xlsx): Completed solution workbook.

---

## Learning Focus

- Writing and applying Excel formulas.
- Using functions to calculate and transform worksheet data.
- Organizing data for efficient analysis.
- Checking calculated results against the expected output.

---

## Outcome

By the end of the day, learners should be able to apply common Excel functions to solve practical data analysis tasks and produce a reliable spreadsheet solution.
