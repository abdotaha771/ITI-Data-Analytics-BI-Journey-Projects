# Day 14: Advanced Excel and Dashboard Preparation

This day applies an end-to-end analytical workflow to the **AdventureWorks** database. The work follows the instructor's lecture: extract selected tables, transform the data, create a date dimension, build a data model, generate insights, and use those insights to design a dashboard.

---

## Source Database

The practical work uses the following AdventureWorks tables:

- `Product`
- `ProductSubcategory`
- `ProductCategory`
- `SalesOrderDetail`
- `SalesOrderHeader`
- `SalesTerritory`
- `ShipMethod`

These tables provide product, category, order, territory, and shipping information for the analysis.

---

## Workflow Covered

1. Get the required data from the AdventureWorks database.
2. Transform and prepare the extracted data for analysis.
3. Create a date dimension to support time-based analysis.
4. Build the analytical data model and define the required relationships.
5. Explore the model and identify useful business insights.
6. Build a dashboard based on the resulting analysis.

---

## Dashboard Requirements

The dashboard should include, at minimum:

- 4 charts
- 2 slicers
- 3 cards

The visualizations should communicate meaningful insights from the modeled AdventureWorks sales data.

## Outcome

By the end of the day, learners should understand how to move from source data to a modeled analytical dataset and then use that model to create an insight-driven dashboard.
